HY ERICA 캐릭터 사용 승인센터 v1.1

구성
- index.html : 메인 페이지
- assets/hanyang-card.webp : 하냥이 카드 이미지
- assets/hibibi-card.webp : 하이비비 카드 이미지
- assets/hanyang_manual.pdf : 하냥이 매뉴얼
- assets/hibibi_manual.pdf : 하이비비 매뉴얼

배포
1. GitHub 저장소에 index.html과 assets 폴더를 그대로 업로드
2. Settings > Pages에서 main / root 선택
3. 배포 완료 후 생성된 Pages 주소로 접속

현재 v1.1 제출 방식
- 페이지 안에서 사용 가능 여부 자동 판정
- 필요한 경우 신청 정보 작성
- '담당자에게 메일 작성' 버튼으로 hyerica@hanyang.ac.kr 메일 초안 자동 생성
- 신규 시안 파일은 브라우저 보안상 메일에 자동 첨부되지 않으므로 메일 창에서 직접 첨부

다음 버전에서 가능한 확장
- Google Apps Script 백엔드 연결
- 신청 내용을 Google Sheets에 자동 기록
- 신규 시안 파일을 Google Drive에 자동 저장
- 담당자에게 자동 메일 발송
- 관리자 승인/반려 상태 관리 및 신청번호 조회
